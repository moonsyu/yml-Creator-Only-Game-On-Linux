모드 설치에 필요한 파일을 함께 받으려면 실행 묶음 ZIP을 사용하세요. 서버에서 ZIP 전체를 풀고 그 폴더에서 docker compose up -d를 실행하면 모드 설치 후 서버가 시작됩니다.

서버에서 실행하는 방법
  1. Linux 서버에 Docker와 Docker Compose 플러그인을 설치합니다.
  2. 새 폴더를 만들고 내려받은 docker-compose.yml을 넣습니다.
  3. 그 폴더에서 docker compose up -d를 실행합니다.
  4. docker compose logs -f로 첫 설치 진행 상황을 확인합니다. 첫 실행은 게임 파일 다운로드로 수 분이 걸립니다.
  5. 방화벽과 공유기에서 YML의 ports에 적힌 포트를 엽니다.
